# 🧟 Zombie Survival — by Amanda

Game survival zombie berbasis HTML5 Canvas. Single player & split-screen multiplayer.

## Cara Main
Buka `index.html` di browser modern (Chrome/Edge/Firefox).

## Kontrol
- **P1:** WASD gerak, SPASI tembak, R reload, 1-5 pilih senjata
- **P1 Ability:** E bom, F dash, Q heal
- **P2 (multi):** Panah gerak, ENTER tembak, SHIFT reload, TAB ganti senjata
- **P2 Ability:** / bom, . dash, ' heal
- **ESC:** jeda

## Fitur
- 4 tingkat kesulitan
- 5 tipe zombie + boss tiap wave ke-5
- Sistem evolusi senjata
- Split-screen lokal untuk 2 pemain
